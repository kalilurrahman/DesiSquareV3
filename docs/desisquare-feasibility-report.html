01

The one-line verdict

This is a buildable, sensible stack — but it is an integration of three independent systems, not a product with a customization dial. Each pillar customizes differently, and the whole design follows from respecting that.

The decision everything hinges on

Let Discourse carry the bespoke, wireframe-driven UI. Keep Ghostfolio close to stock as an embedded portfolio module. Use WhatsApp for notifications only. Fighting that grain — pixel-matching Ghostfolio to a wireframe, or forcing WhatsApp to be the discussion surface — is where the project fails.

What the demo actually is

desisquare-production.up.railway.app is a self-hosted, rebranded Ghostfolio instance on Railway — the open-source wealth/portfolio tracker (Angular + NestJS + Prisma + PostgreSQL + Redis, delivered as a PWA).

What "give me what's in the example" scopes to

  • Self-host Ghostfolio on infrastructure you control
  • Rebrand it — name, logo, palette, favicon, domain
  • Wire it in to the forum (shared login) & WhatsApp (alerts)

What you get out of the box

Home dashboard · holdings & activities · allocations & X-ray analysis · dividends · benchmarks · FIRE calculator · multi-account · CSV/JSON import · watchlist · Zen & dark mode · public portfolio sharing · REST API.

Honest caveat

Automated inspection can't load the live DOM (it returns 403 to non-browser fetches — normal for an SPA behind a proxy). It is rebranded Ghostfolio, but any DesiSquare-specific bespoke screens can't be confirmed from here. Step one is a live walkthrough with you to lock the exact scope — and to catch anything custom that would add cost. Their own member data and any bespoke code cannot be copied; only the open-source app can.

04

Discourse from your wireframe

The strong pillar. Discourse's theme system reskins and re-lays-out the UI through SCSS, colour palettes, HTML injection and theme JavaScript (plugin outlets) — without forking core, which is why it stays upgrade-safe. Treat the wireframe as design direction, not a pixel contract.

Wireframe elementFeasibilityMechanism
Brand colours, type, spacing, buttons, cards, light/dark palettesFullySCSS + 10-key colour schemes
Custom header / top nav / navbarFullyTheme components + header injection
Bespoke homepage replacing the topic listFullycustom-homepage route + outlet
Custom sidebar, hero / section blocksFullySidebar API + plugin outlets
Replace a region that has a plugin outletMostlyWrapper outlet ({{yield}})
Restructure a region with no outletCostlymodifyClass — breaks on upgrade
Whole-template markup rewritesAvoid.hbs overrides deprecated Nov 2024
A new server-backed page / route (new data)Not a themeRequires a Ruby plugin → self-host / Enterprise

Verdict: yes for branding, homepage, navigation, sidebar, hero and card/list styling — typically 80–90% of a community wireframe. Build only against Glimmer-era APIs (the legacy "widget" system is being retired), and price any modifyClass or plugin work as higher-risk with an upgrade-testing retainer. Discourse also ships a built-in real-time Chat and mature SSO, and its licence is GPLv2 (no network-use trigger).

05

Ghostfolio — the hard part

Yes, its appearance can be customized — but by a fundamentally more expensive mechanism. Ghostfolio has no white-label / theming admin panel. Colours live in compiled SCSS; the name and logo are hard-coded in source. Every real rebrand means editing Angular source and maintaining a fork.

The #1 hidden cost: fork maintenance

Ghostfolio ships ~100 releases a year. Because your changes live inside the same files as upstream, every upgrade risks merge conflicts — realistically 1–3 engineer-days/month, which usually exceeds the entire server bill. Under-scope it and you get a stale, unpatched fork.

The licence you must accept: AGPLv3

Hosting a modified Ghostfolio as a public service obliges you to offer your users your modified source (Section 13). Rebranding counts as modification. Satisfiable with a source link in the footer — but get the client's written acceptance before building.

Recommendation — the load-bearing one

Scope Ghostfolio as a bounded reskin — palette, logo, name, favicon, feature-hiding — not a wireframe-driven layout rebuild. Push all bespoke UI into Discourse. Validate the reskin with a 1-week fork spike before any fixed-price commitment. And don't use Ghostfolio's native "security-token" login for a community (no account recovery) — front it with the shared OIDC IdP.

Data & ops note: live quotes work free out of the box (Yahoo Finance + CoinGecko, no API key). But Yahoo is unofficial/rate-limited and thin on Indian tickers — budget a paid provider (EOD or Financial Modeling Prep, ~$20–80/mo) for production Indian-equity coverage. Ghostfolio stores all members in one shared database with app-level isolation — mandate per-user isolation security testing before opening a wealth community to it.

06

WhatsApp — the reality check

WhatsApp cannot be the forum. Meta did add an official Groups API (Oct 2025) — but it caps groups at 8 members, works only on business-created groups, and needs a verified Official Business Account. It's a concierge tool, not a community. The unofficial libraries that can drive real groups violate Meta's Terms and risk permanent number bans.

The right model is hybrid, not WhatsApp-only

Cost model: since Jul 2025 WhatsApp bills per delivered message by category. User-initiated replies and utility templates inside the service window are free; marketing is always billed (and blocked to US +1 numbers since Apr 2025). Engineer notifications as utility templates wherever legitimate — mis-classifying utility as marketing multiplies cost ~8×.

09

Compliance guardrails

An investment community sits in the most scrutinized content zone. These are considerations to confirm with counsel — not legal advice.

Highest legal risk

SEBI / "finfluencer"

SEBI's 2024–25 rules bar association with unregistered advice-givers; a Dec 2025 order impounded ₹546+ crore. "Educational" framing is not a safe harbour if anyone gives buy/sell calls or return guarantees. Position as education + self-directed tracking only; get securities counsel on any paid tier.

Licences

AGPLv3 & GPLv2

Ghostfolio (AGPLv3) → publish your modified source to users. Discourse (GPLv2) → distribution-only copyleft. Keep them as separate services; the licences are incompatible if code-combined.

Consent

WhatsApp & opt-in

Named opt-in, no pre-checked boxes, separate promotional consent, STOP opt-out. Marketing to US (+1) numbers is blocked — use utility/auth or email there.

Data

DPDP & GDPR

Portfolio data reveals net worth — treat as sensitive. India DPDP Act 2023 (Rules Nov 2025): purpose-specific consent, grievance officer, likely Significant Data Fiduciary duties. Add a GDPR flow if EU/UK members join. Pervasive "not investment advice" disclaimers everywhere.

10

Final recommendations

  • Green-light the build as a phased integration project — Foundations → Branded MVP → Depth.
  • Discourse carries the bespoke UI — git-hosted theme + components from your wireframes; treat the wireframe as direction, price plugin work separately.
  • Ghostfolio stays close to stock — reskin only, fork-maintenance retainer budgeted visibly, written AGPLv3 acceptance first.
  • WhatsApp is a notification/support channel, never the forum — utility-first templates, real opt-in; add Telegram + email; exclude unofficial bridges.
  • One external OIDC IdP, shared injected header (not iframes), n8n as the events-to-notifications hub.
  • Self-host for full theme/plugin control — managed Discourse tiers won't allow this customization at a reasonable price.
  • Bake in compliance from day one — educational-only positioning, pervasive disclaimers, correct opt-in, DPDP/GDPR handling.
  • Two concrete first steps: a live DesiSquare walkthrough to lock scope, and a 1-week Ghostfolio reskin spike to firm up the fork estimate.
